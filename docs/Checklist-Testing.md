# Checklist Testing — Banyu Frozen Food

Panduan uji manual untuk memastikan website + panel admin CMS berjalan baik.
Centang `[x]` setiap item yang lolos. Isi kolom **Hasil** bila ada catatan/gagal.

Cara pakai:
1. Jalankan `npm run dev`, buka `http://localhost:5173`.
2. Pastikan `supabase-schema.sql` sudah dijalankan di Supabase SQL Editor (agar data tersimpan online, bukan di browser saja).
3. Siapkan akun admin (dibuat manual di Supabase Authentication, lihat `docs/Dokumentasi-Panel-Admin.md`).
4. Kerjakan tiap bagian berurutan. Buka DevTools Console (F12) — **tidak boleh ada error merah** kecuali 404 tabel yang memang belum dibuat.
