# Consistent Location Section Design

## Intent

Make bottom homepage location section feel like same page as sections above, not like separate location page.

## Design

- Use existing `.section-title` pattern for location heading.
- Use white section background and normal homepage spacing.
- Remove location-specific blue gradient header treatment.
- Keep map, contact cards, service-area card, gallery, CMS data, and responsive behavior unchanged.

## Non-goals

- No route, CMS data, copy, analytics, or location functionality changes.
- No new dependencies or visual component system.
